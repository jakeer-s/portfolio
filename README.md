## 🚀 How to Run Locally

### Option 1: Direct Browser Launch
Simply double-click `index.html` or open it with any web browser (Chrome, Edge, Firefox, Brave).

### Option 2: Local Static Server (PowerShell / Python / Node)

Using Python:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.

Using Node.js (`npx serve`):
```bash
npx serve .
```

## 🌐 Free 1-Click Deployment Options

### 1. GitHub Pages (Recommended)
1. Initialize a git repository and commit your files:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   ```
2. Create a new repository on [GitHub](https://github.com) named `portfolio` or `shaikjakeer.github.io`.
3. Push your repository:
   ```bash
   git remote add origin https://github.com/<your-username>/portfolio.git
   git branch -M main
   git push -u origin main
   ```
4. In GitHub, go to **Settings > Pages > Source**, choose `main` branch, and click **Save**. Your site will be live at `https://<your-username>.github.io/portfolio/`!

### 2. Vercel or Netlify
- Drag and drop this folder onto [Netlify Drop](https://app.netlify.com/drop) or import from GitHub on [Vercel](https://vercel.com).
- No build command needed — it deploys instantly as a static site.
